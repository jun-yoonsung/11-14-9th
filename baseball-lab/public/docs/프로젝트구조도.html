프로젝트 구조도

이 사이트가 어떤 부품으로 이루어져 있고, 데이터가 어디서 어디로 흘러가는지 한 장으로 정리했습니다.

살펴본 범위: baseball-lab 폴더의 화면 코드(src/, React), 설정(package.json, vite.config.js), 공개 파일(public/), 변환·업로드 스크립트(build_data.py, tools/), 보안 규칙(firestore.rules), 배포 설정(.github/workflows/pages.yml). 코드에서 직접 확인한 내용만 그렸습니다. (실제 로그인·DB는 코드가 준비돼 있지만 연결 값이 비어 있어, 연결 전 상태 기준으로 그리고 연결 후 모습은 점선으로 표시했습니다.)

한 줄 요약. 지금은 직접 운영하는 서버가 없습니다. 화면은 React + Tailwind CSS로 만들어 GitHub가 자동으로 빌드(코드를 배포용 파일로 변환)해 올리고, 브라우저가 파일(화면, CSV 표)을 받아와서 계산과 보고서 만들기를 전부 직접 합니다. 다만 Firebase(실제 로그인 + DB)를 붙일 수 있게 코드가 준비돼 있고, src/config.js에 연결 값을 넣으면 켜집니다. 값이 비어 있는 지금은 꺼져 있어서 체험 로그인과 브라우저 저장소를 씁니다.

그림 속 표시 읽는 법

🔑 비밀 키가 쓰이는 곳 (빨간 테두리)사이트 코드에는 없음. 단, DB에 CSV를 올리는 도구(tools/upload_firestore.py)가 쓰는 서비스 계정 키 파일은 비밀입니다. 사이트 폴더에 두거나 GitHub에 올리면 안 됩니다.
💰 사용량에 따라 요금이 생길 수 있는 곳Firestore(DB)를 켜면 읽기·쓰기 횟수에 따라 요금이 생길 수 있습니다. 요금 조건은 코드만으로 알 수 없어 미확인으로 표시했습니다.
🌐 브라우저에 공개되는 영역누구나 내려받거나 볼 수 있는 파일과 화면입니다.
🔒 서버 안쪽 영역직접 만든 서버 코드는 없음. Firebase를 켜면 접근 제한은 Firebase의 보안 규칙(firestore.rules)이 맡습니다.
점선 박스 = 미확인코드에서 확인하지 못한 부분입니다. 추측하지 않았습니다.

핵심 기능 한 가지: “선수 분석하고 보고서 받기”

선수를 골라 분석을 시작해서 PDF를 받을 때까지, 데이터가 지나가는 순서입니다.

  1. 사용자분석 설정을 고릅니다. 분석 방식과 데이터 출처를 고르고, 타자·투수 중 선택, 선수 검색, 볼 지표를 고른 뒤 “분석하기”를 누릅니다.파일: src/pages/Analyze.jsx, src/components/PlayerCombo.jsx (선수 검색, 초성 검색 포함)
  2. 화면 → 파일 배달필요한 CSV 파일을 요청합니다. 선수 목록(batters.csv 또는 pitchers.csv), 규정 기준(meta.json), 월별·구종 파일을 내려받습니다.파일: src/lib/api.js (fetch로 data/ 폴더 읽기. Firebase가 켜져 있으면 Firestore에서 먼저 읽음)
  3. 화면 (브라우저 안)지표를 계산합니다. 선택한 지표(타율·OPS 같은 기록 지표, 컨택%·Chase% 같은 선구안 지표, FIP·K/BB 같은 투수 지표. “전체 지표 분석”을 누르면 전부)를 계산하고, 규정을 채운 선수들과 비교해 리그 평균과 순위(백분위)를 구합니다.파일: src/lib/stats.js
  4. 화면 (브라우저 안)상세 보고서를 만듭니다. 타자는 타격 5개 영역과 안타 구성, 투수는 투구 5개 영역·9이닝 결과·구종 구성을 계산합니다. 강점·보완점, 월별 추이, 비슷한 선수도 함께 만듭니다.파일: src/lib/detail.js
  5. 브라우저 저장소결과를 분석 기록에 저장합니다. 계산된 값을 그대로 저장해서, 나중에 열어도 같은 결과가 나옵니다.저장 위치: localStorage의 bl_history_kbo (src/lib/storage.js). 실제 로그인이면 Firestore의 내 계정 아래에도 저장 (src/lib/cloud.js)
  6. 화면 → 사용자결과 화면을 보여 줍니다. 핵심 수치, 리그 안에서의 위치, 상세 분석 보고서를 한 화면에 그립니다.파일: src/pages/Result.jsx, src/components/DetailReport.jsx, PctBlock.jsx
  7. 화면 → 사용자“PDF로 저장”을 누르면 5쪽 PDF를 내려받습니다. 눌렀을 때 PDF 도구(html2pdf.js, 사이트 파일에 포함되어 필요할 때만 로드)로 보고서 화면을 PDF로 바꾸고, 내 컴퓨터에 파일로 저장합니다.파일: src/lib/report.js + html2pdf.js 패키지
