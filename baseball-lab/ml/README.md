# 예측 모델 정리 (앞으로 5년 성적·현역 확률)

결과 화면의 "앞으로 5년 예측"을 만드는 모델의 데이터, 방법, 정확도, 한계를 한곳에 정리한 문서입니다.

## 1. 무엇을 예측하나
| 대상 | 예측값 | 시점 |
|---|---|---|
| 타자 | OPS(출루율+장타율) | 1~5년 뒤 |
| 투수 | ERA(평균자책점) | 1~5년 뒤 |
| 타자·투수 | 그 해에도 KBO 1군 기록이 남아 있을 확률(현역 확률) | 1~5년 뒤 |

- 은퇴 예상 나이는 현역 확률이 50% 아래로 처음 내려가는 나이입니다. 5년 안에 내려가지 않으면 "5년 안에는 높게 유지"로 표시합니다.
- 현역 확률은 부상, 군 복무, 해외 진출도 "기록 없음"으로 잡습니다. 은퇴의 정확한 연도를 맞히는 모델이 아닙니다.
- 성적 예측은 "그 해에 충분히 뛴다(타자 100타석, 투수 30이닝 이상)"는 가정의 값입니다.

## 2. 데이터
- Kaggle **KBO Player Stats 1982–2026** (작성자 netsong, KBO 공식 기록 기반, **CC BY-NC-SA 4.0**).
- 선수 한 명의 한 시즌이 한 행입니다(타자 10,209행, 투수 7,971행). 나이(`Age`), 생년월일(`Born`)과 KBO 선수 번호(`Id`)가 있습니다.
- 우리 사이트의 `pid`와 같은 번호입니다(2026 투수 296명 전원 일치, 자책점·삼진 값 일치 확인).
- **원본 CSV는 재배포 금지 라이선스라 GitHub에 올리지 않습니다**(`ml/raw/`는 `.gitignore`). 예측 결과와 출처 표기만 공개합니다. 비영리 수업 프로젝트에서만 사용합니다.
- KBO 공식 사이트(koreabaseball.com)는 `robots.txt`가 검색 엔진 외 자동 수집을 금지하므로 직접 수집하지 않았습니다.

## 3. 방법
1. 선수-기준시즌마다 최근 3시즌 기록, 나이, 경력, 리그 평균을 특성으로 만들고, t+1~t+5 시즌 기록을 정답으로 붙입니다(`train_forecast.py`).
2. 1990 시즌 이후 자료만 학습에 씁니다. 시점(1~5년 뒤)마다 모델을 따로 학습합니다.
3. **시간 순서 검증**: 학습(예측 대상 ~2020) → 구간 폭 보정과 모델 선택(2021~2023) → 시험(2024~2026). 시험 구간은 학습·보정·선택에 쓰지 않습니다.
4. 비교 기준선 3가지: 작년 값, 최근 3시즌 가중평균(Marcel식), 리그 평균. 시점마다 검증 구간에서 가장 나은 방법을 자동으로 고릅니다.
5. 80% 예측 범위는 분위수 회귀로 만들고, 검증 구간에서 실제로 80%가 들어오도록 폭을 보정합니다.

## 4. 모델 비교와 선택
`compare_models.py`(성적), `compare_classifiers.py`(현역 확률). 결과는 `model_comparison.json`.

| 대상 | 비교한 후보 | 선택(검증 구간 기준) |
|---|---|---|
| 타자 OPS | Ridge, 랜덤포레스트, ExtraTrees(2종), HGB 4종, XGBoost 2종, LightGBM 2종, CatBoost 3종, 신경망(MLP), 시계열 GRU, 앙상블 14종(`compare_ensembles.py`) | **ExtraTrees + XGBoost + CatBoost + 신경망 평균**(검증 0.0764) |
| 투수 ERA | 같은 후보, 앙상블 9종 | **CatBoost(MAE 손실)** 단독(검증 1.0616) |
| 현역 확률 | 로지스틱, 랜덤포레스트, ExtraTrees, HGB 2종, XGBoost, LightGBM, CatBoost 2종, 신경망 | 타자 HGB, 투수 CatBoost(깊게)(검증 Brier 1등, 2~3등과 차이 작음) |

- 2026-11-18 재비교: CatBoost 3종과 신경망(MLP)을 후보에 더해 같은 규칙(검증 구간으로만 선택)으로 다시 골랐습니다. 후보들의 오차 차이는 매우 작아(타자 검증 0.0764~0.0795, 투수 1.06~1.15) 새 구성이 시험 구간에서 확실히 낫다고 말할 수는 없습니다. 실제로 시험 구간 평균 오차는 타자 1~5년 0.070/0.071/0.079/0.075/0.077, 투수 1.079/1.115/1.219/1.162/1.081로, 이전 구성(타자 3년 0.076·5년 0.073, 투수 3년 1.185·5년 1.054)보다 1~2년은 비슷하거나 약간 좋고 3~5년은 약간 나빴습니다. 시험 결과를 보고 되돌리지 않았습니다. 신경망 단독은 검증 0.0835(타자)·1.117(투수)로 트리 계열보다 못했고, 다른 지표(출루율 등) 예측은 위 구성을 그대로 재사용합니다.
- 2026-11 갱신: XGBoost·LightGBM을 후보에 추가하고, 입력 정보에 키·몸무게·좌우 타투·드래프트 순번·결장 시즌 수를 더했습니다. 보정·시험은 기준 시즌에 타자 50타석·투수 20이닝 이상 뛴 선수만 씁니다(정규 출전 선수 기준 정확도). 학습·예측 대상은 타자 10타석·투수 5이닝 이상으로 넓혀 예측 선수가 381명에서 494명이 됐습니다(표본이 작은 선수는 화면에 안내).
- 팀 승률 예측은 `train_team.py`(1~3년 뒤, Ridge·ExtraTrees·CatBoost·기준선 중 검증 1등. CatBoost는 뽑히지 않음)로 따로 만들고 `team_forecast.json`에 저장합니다. 선수 기록을 팀·시즌별로 합산해 팀 성적표를 만들고, 구단 이름이 바뀐 팀(OB→두산 등)은 이어 붙입니다.
- 커리어(시즌별 기록)는 `build_career.py`가 1982년 이후 모든 선수의 시즌별 기록을 `career.json`으로 만듭니다(현역 선수에게만 예측선이 붙습니다).

## 5. 정확도 (시험 구간 2024~2026, 평균 오차 / 낮을수록 좋음)
| | 1년 뒤 | 3년 뒤 | 5년 뒤 |
|---|---|---|---|
| 타자 OPS(선택된 방법) | 0.070 | 0.079 | 0.077 |
| 타자 OPS(작년 기록 그대로) | 0.092 | 0.097 | 0.109 |
| 투수 ERA(선택된 방법) | 1.079 | 1.219 | 1.081 |
| 투수 ERA(작년 기록 그대로) | 1.445 | 1.567 | 1.641 |

- 80% 범위에 실제 값이 들어온 비율은 75~93%입니다.
- 현역 지속 구분력(AUC)은 0.79~0.83입니다.
- 팀 승률(시험 2019~2026, 팀·시즌 80개): 1년 뒤 평균 오차 0.055(작년 승률 0.068), 2년 0.058(0.071), 3년 0.062(0.071). 3년 뒤는 사실상 .500으로 수렴하는 방법이 뽑혔습니다.
- 최신 수치는 `metrics.json`과 화면의 "이 예측은 얼마나 믿을 수 있나요?"에서 확인합니다.

## 5-1. 다른 지표 예측 (`train_forecast_extra.py`)
- 대상: 타자 출루율·장타율·삼진 비율·볼넷 비율·홈런 비율, 투수 WHIP·9이닝당 삼진·9이닝당 볼넷·9이닝당 피홈런. 같은 시간 순서 검증(학습 ~2020, 보정·선택 2021~2023, 시험 2024~2026)과 80% 범위 보정을 쓰고, 지표·시점마다 작년 값/Marcel/리그 평균/모델 중 검증 1등을 고릅니다.
- 지표마다 모델 구성 4가지(타자: 4모델 평균/ExtraTrees/CatBoost/ExtraTrees+XGBoost, 투수: CatBoost(MAE)/LightGBM(MAE)/ExtraTrees/ExtraTrees+CatBoost(MAE))를 검증 구간 오차로 따로 고릅니다(고른 구성은 `forecast_extra.json`의 `meta.stats[].model`). OPS·ERA만큼 후보를 넓게 비교하지는 않아 **참고용**입니다. 지표별 시험 오차와 80% 적중률은 `forecast_extra.json`의 `meta.metrics`와 화면 안내에 있습니다.
- 팀 간 상대 전적, 경기별 기록은 데이터에 없어 다루지 않습니다.

## 6. 한계 (솔직한 정리)
- **"제일 정확한 모델"이라고 보장하지 않습니다.** 후보 중 검증 구간 기준 최선이며, 타자는 트리 계열 모델끼리 차이가 사실상 없었습니다.
- 투수 시험 구간 표본이 146~282개로 작아서 모델 사이의 작은 차이는 우연일 수 있습니다. 시험 구간에서는 ExtraTrees(큰)(1.106)·랜덤포레스트(1.106)가 선택된 CatBoost(MAE)(1.132)보다 나았지만(1~5년 평균), 시험 결과를 보고 모델을 바꾸지 않았습니다.
- 투수 3년 뒤(1.219)와 4년 뒤(1.162)는 리그 평균(각 1.176, 1.152)보다 약간 나쁩니다. 검증 구간에서는 모델이 더 나았기 때문에 그대로 두었고, 먼 시점의 투수 ERA는 특히 참고용으로만 봐야 합니다.
- 팀 승률 예측은 표본이 작고(구단 10곳) 선수 이동을 반영하지 않아 참고용입니다. 구단 계보는 약식으로 이었습니다(넥센·우리·히어로즈→키움 등).
- XGBoost·LightGBM·CatBoost·신경망은 비교했고 차이는 작았습니다(타자 시험 0.0711~0.0783, 투수 1.106~1.155). 선수별 시계열 모델(GRU: 최근 3시즌을 순서대로 입력)도 비교했지만 단독(타자 검증 0.0799, 투수 1.0805)이나 앙상블에 넣어도 검증 1등이 되지 못해 쓰지 않았습니다. 데이터가 선수당 몇 시즌뿐이라 순서 정보를 쓰는 이점이 거의 없었습니다.
- 특성이 기록·나이·경력 위주입니다. 부상, 군 복무, 구속 변화, 타구 질은 반영하지 못합니다.
- 먼 미래일수록 불확실성이 큽니다. 한 시즌 값이 아니라 80% 범위를 함께 봐야 합니다.
- 성적 예측은 "그 해에 뛴 선수"만 대상으로 학습해, 뛰지 못하는 경우의 성적은 말하지 않습니다.

## 7. 다시 학습하는 방법
1. Kaggle에서 CSV 2개를 받아 `ml/raw/`에 둡니다(`kbo_batting_stats_season_1982-2026.csv`, `kbo_pitching_stats_season_1982-2026.csv`).
2. `python3 ml/train_forecast.py` → `public/data/forecast.json`, `ml/metrics.json` 갱신.
3. 커리어·팀: `python3 ml/build_career.py`, `python3 ml/train_team.py`.
3-1. 다른 지표 예측: `python3 ml/train_forecast_extra.py` → `forecast_extra.json`. 과거 시즌·역대 기록: `python3 ml/build_history.py` → `batters_hist.csv`, `pitchers_hist.csv`, `teams_hist.csv`, `records.json`. 2026 값을 공식 집계로 맞춤: `python3 ml/fix_official.py`(여러 번 실행해도 같은 결과, 바뀐 값은 `data_quality.json`).
4. 모델을 다시 비교하려면 `python3 ml/compare_models.py`, `python3 ml/compare_ensembles.py`, `python3 ml/compare_classifiers.py`.
5. 필요한 패키지: pandas, numpy, scikit-learn, xgboost, lightgbm.

# AI 해설 (참고)
- 사이트에서 LLM을 부르지 않고, `tools/gen_commentary.mjs`로 미리 생성해 `public/data/commentary.json`에 저장합니다(키 노출·비용·대기·문장 변동 방지).
- LLM에는 계산된 수치만 주고, 결과 문장의 숫자가 그 수치에 없으면 버리고 다시 만듭니다(최대 3회).
- 생성 대상: 기본 50타석 이상 타자, 15이닝 이상 투수(`--min-pa`, `--min-outs`로 조정). 선수 전체 해설에 더해 강점·약점 지표별 한 문장(`metrics`)을 함께 만들고, 화면과 PDF의 "고른 지표 해설"은 AI 문장이 없는 지표를 계산값으로 만든 문장으로 채웁니다.
- 팀 해설은 `node tools/gen_team_commentary.mjs`로 `team_commentary.json`을 만듭니다.
- 키는 `tools/.env`에 넣으며 GitHub에 올라가지 않습니다.
