# 야구 분석 랩 디자인 시스템

토큰은 `src/index.css` 맨 위 `@theme`에 모여 있습니다. 새 화면을 만들 때는 색·크기·모서리 값을 직접 쓰지 말고 아래 토큰을 쓰세요.

## 토큰

| 구분 | 이름 | 값 | 쓰임 |
|---|---|---|---|
| 색 | `--ink` / `--ink-2` | #0d1a38 / #1a2b55 | 글자, 어두운 전광판 면 |
| 색 | `--paper` / `--white` | #f4f6fa / #fff | 배경, 카드 |
| 색 | `--blue` / `--blue-soft` | #2146c7 / #e9eefc | 주요 행동, 선택 상태 |
| 색 | `--red` / `--red-soft` | #d0312d / #fdecea | 오류, 삭제, 현재 메뉴 표시 |
| 색 | `--green` / `--green-soft` | #17734f / #e3f3ec | 리그보다 좋은 기록 |
| 색 | `--muted` / `--line` / `--line-soft` / `--track` | #566383 / #d8deea / #e5e9f2 / #8d9ab8 | 보조 글자, 테두리, 막대 바탕·막대 |
| 글자 | `--t-xs` / `--t-sm` / `--t-md` / 1rem | .78 / .85 / .9 / 1rem | 주석 / 표·보조 / 라벨 / 본문 |
| 글꼴 | `--display` / `--sans` | Do Hyeon / Noto Sans KR | 제목·숫자 / 본문 |
| 모서리 | `--r-sm` / `--r-md` / `--r-lg` / `--r-pill` | 6 / 8 / 14px / 999 | 칩·막대 / 버튼·입력 / 카드 / 알약 |
| 그림자 | `--shadow-card` / `--shadow-pop` | | 카드 / 배경 위로 올라온 본문 |

## 버튼 (`.btn`)

| 변형 | 클래스 | 쓰는 때 |
|---|---|---|
| 기본 | `btn` | 보조 행동 (기록 보기 등) |
| 주요 | `btn pri` | 화면에서 가장 중요한 행동 한 개 |
| 고스트 | `btn ghost` | 이전, 취소, 다시 분석처럼 가벼운 행동 |
| 위험 | `btn danger` | 삭제 확인 |
| 크기 | `small`, `lg` | 표 안 / 첫 화면 시작 버튼 |
| 너비 | `block` | 폼 맨 아래 가로 꽉 채움 |

상태: hover(색 반전), active(1px 눌림), disabled(투명도 50%), loading(`aria-busy="true"`, 글자 대신 회전 표시), 키보드 포커스(파란 3px 윤곽선).

## 접근성

- 모든 버튼·링크는 키보드로 닿고 `:focus-visible` 윤곽선이 보입니다.
- 로딩 중인 버튼은 `aria-busy`로 상태를 알리고 `disabled`로 중복 클릭을 막습니다.
- 3D 배경 위의 글씨는 어두운 반투명 패널이나 그림자 위에만 놓습니다.
- 움직임 줄이기 설정이면 배경 애니메이션을 멈춥니다.
