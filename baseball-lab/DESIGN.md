# 야구 분석 랩 DESIGN.md

기준: [getdesign.md](https://getdesign.md/)의 **Linear** 디자인 시스템(독립 분석본). 숫자·기록을 빠르고 정확하게 읽어야 하는 분석 도구라서, 장식을 덜고 표면·가는 선·하나의 포인트 색으로 위계를 만드는 Linear 방식이 가장 잘 맞다고 판단했습니다. Linear는 어두운 화면 전용이라 그대로 가져오지 않고, **원칙만 가져와 우리 화면(어두운 3D 구장 + 밝은 본문 패널)에 맞게** 바꿨습니다.

## 가져온 원칙과 적용

| Linear 원칙 | 야구 분석 랩 적용 |
|---|---|
| 포인트 색은 하나, 용도는 주요 버튼·포커스·링크뿐 | `--blue #5e6ad2`(라벤더 블루). 빨강·초록은 "좋음/나쁨, 오류"라는 의미 색으로만 씀 |
| 그림자 대신 표면 단계와 1px 가는 선 | 카드·입력·버튼 테두리를 1px `--line`으로 통일 (예전 1.5px 진한 선 제거) |
| 제목은 굵게 + 글자 간격 좁게, 본문은 보통 굵기 | h1~h3: Noto Sans KR 700, 자간 -0.03em. 숫자·로고만 Do Hyeon(전광판 느낌) 유지 |
| 4px 기준 간격, 버튼 8px 모서리, 카드 12px | `--r-md 8`, `--r-lg 12`, `--r-xl 16`(배경 위 본문 패널). 알약은 칩·태그에만 |
| 버튼은 작고 단단하게 (14px, 500) | 14px/600, 높이 40px(작은 버튼 32px, 큰 버튼 48px) |
| 상단 메뉴 56px, 군더더기 없음 | 헤더 62px → 56px |
| 포커스는 2px 윤곽선 | `:focus-visible` 2px 파랑, 오프셋 2px |
| 포인트 색을 배경·카드 채움에 쓰지 않음 | 파랑은 버튼·선택 표시·링크에만. 카드 배경은 흰색/회색 단계 |

## 토큰 (`src/index.css` 맨 위 `@theme`)

| 구분 | 이름 | 값 | 쓰임 |
|---|---|---|---|
| 글자·어두운 면 | `--ink` / `--ink-2` | #101216 / #1c1f26 | 본문 글자, 전광판 면 |
| 바탕 | `--paper` / `--white` | #f6f7f9 / #fff | 페이지, 카드 |
| 선 | `--line` / `--line-soft` | #e1e4ea / #eceef2 | 테두리 / 막대 바탕 |
| 보조 글자 | `--muted` | #5b6270 | 설명, 비활성 |
| 포인트 | `--blue` / `--blue-soft` | #5e6ad2 / #eceefb | 주요 버튼, 선택, 링크 (hover #4f5ac0) |
| 의미 | `--red` / `--green` (+`-soft`) | #d0312d / #17734f | 오류·삭제 / 리그보다 좋은 기록 |
| 글자 크기 | `--t-xs` / `--t-sm`=`--t-md` / 1rem | 12.5 / 14 / 16px | 주석 / 표·라벨·버튼 / 본문 |
| 모서리 | `--r-sm` / `--r-md` / `--r-lg` / `--r-xl` / `--r-pill` | 6 / 8 / 12 / 16 / 999 | 칩 / 버튼·입력 / 카드 / 본문 패널 / 알약 |
| 간격 | 4px 배수 | 4 8 12 16 24 32 48 | 여백 기준 |

## 버튼 (`.btn`)

| 변형 | 클래스 | 모양 | 쓰는 때 |
|---|---|---|---|
| 주요 | `btn pri` | 파랑 채움, 흰 글자 | 화면에서 가장 중요한 행동 한 개 |
| 기본 | `btn` | 흰 바탕 + 1px 선 | 보조 행동 |
| 고스트 | `btn ghost` | 투명, 보조 글자색 | 이전·취소·다시 분석 |
| 위험 | `btn danger` | 흰 바탕 + 빨간 글자 | 삭제 확인 |
| 크기·너비 | `small` 32 / 기본 40 / `lg` 48 / `block` | | |

상태: hover(바탕 한 단계 어둡게), active(1px 눌림), disabled(50%), loading(`aria-busy`, 회전 표시), 포커스(2px 파랑).

## 하지 않는 것

- 파랑을 카드·섹션 배경으로 쓰지 않는다.
- 포인트 색을 하나 더 늘리지 않는다 (빨강·초록은 의미 전달용으로만).
- 카드에 그림자를 더하지 않는다 (배경 위로 뜬 본문 패널만 예외).
- 버튼을 알약 모양으로 만들지 않는다.

## 접근성

- 모든 버튼·링크는 키보드로 닿고 포커스 윤곽선이 보입니다.
- 흰 글자 on `--blue` 대비 약 4.6:1, `--ink` on 흰색 대비 15:1 이상.
- 로딩 버튼은 `aria-busy` + `disabled`로 상태를 알리고 중복 클릭을 막습니다.
- 움직임 줄이기 설정이면 3D 배경 움직임을 멈춥니다.
